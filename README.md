Das ist das Repository der Web-App der Bachelorarbeit mit dem Titel:
"Nutzerzentrierte Erkennung von KI-Bias mithilfe einer interaktiven Web-App"
von Alexander Günnewig, Matrikelnummer: 524135

Die Web-App ist unter folgender Domain erreichbar:
https://bachelorarbeit-seven.vercel.app

Aktuell ist der Zugriff auf die Studie gesperrt, da sie offiziell beendet wurde.
Diese Sperrung lässt sich mit dem Passwort „alex“ umgehen. Anschließend kann die Studie wie während der offiziellen Durchführungszeit genutzt werden.

Für die lokale Entwicklung wurde eine Datei env.example hinzugefügt, in der die benötigten Keys hinterlegt werden müssen.

Nach dem Wechsel in das Verzeichnis „app“ (cd app) kann der Development-Server mit folgendem Befehl gestartet werden:
npm run dev

Admin-Bereich:
Optional kann über die Route /admin und das Passwort „alex“ der Admin-Bereich aufgerufen werden.
